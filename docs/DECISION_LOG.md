## 2026-06-11 — Pipeline Parameter Tuning & Alert-Trigger Framework Design
- **Decision**: 
  1. Lowered target return label threshold from 5.0% to 1.0% (`label_60m_1pct`) for baseline training.
  2. Reduced SAGA Logistic Regression iterations from 2000 to 150.
  3. Formulated the Alert-Trigger backtest framework (ML Alert -> 9-period ROC Trigger >= 1% / <= -1%).
- **Reason**: 
  1. Clean, uncontaminated stock returns are physically small (standard deviation of ~0.64% over 60 minutes). A 5% threshold led to class starvation (almost 100% NO_TRADE), causing scikit-learn's solvers to crash due to single-class training splits. A 1% threshold provides a healthy distribution of ~12,000 LONG and ~14,000 SHORT samples.
  2. SAGA solver with 2000 iterations takes ~8 minutes per fold (40 minutes total). Reducing iterations to 150 keeps run times under 2 minutes per fold while maintaining baseline model signal capture.
  3. Matches the user's TradingView ROC entry confirmation system. Evaluating targets starting from the actual trigger time ($T_{\text{entry}}$) rather than the model alert time ($t$) provides a realistic simulation of trade execution.
- **Outcome**: 
  - Baseline model run successfully launched on `label_60m_1pct` with optimized SAGA parameters.
  - Planned parameter sweeps for hold horizons (30m, 60m, 120m, 180m) and alert expiration windows (60m to 360m).

## 2026-06-13 — Value Delta (Turnover) Filter & Directional Segmentation
- **Decision**: 
  1. Replaced the share quantity filter (`delta_1m`) with a price-standardized net value-traded turnover filter (`delta_value_1m = delta_1m * Entry Price`).
  2. Segmented filter conditions directionally: LONG trades require `delta_value_1m > 0`, `imbalance_top5 < 0` (ask walls), and `aggressor_ratio >= 0.50`, while SHORT trades require `delta_value_1m < 0`, `imbalance_top5 > 0` (bid walls), and `aggressor_ratio < 0.50`.
  3. Recommended focusing exclusively on LONG trades for high-precision EOD MFE capture.
- **Reason**: 
  1. Share delta (e.g. 4000 shares) created a severe price-scale bias: for a 10 INR stock, 4000 shares is only 40,000 INR, whereas for a 2000 INR stock, it is 8,000,000 INR. Turnover filter normalizes scale across all stock sizes, increasing feature separation by 10x (pooled separation metric boosted from 0.0047 to 0.0454).
  2. Features must be signed directionally: aggressive buying into ask walls creates negative imbalance for LONG winners, while aggressive selling into bid walls creates positive imbalance for SHORT winners.
